# Lucid Disk icon

`AppIcon.png` is the source artwork. `AppIcon.icns` and `AppIcon.iconset/` are mechanically exported by `bash Tools/build_icon.sh`. Transparency outside the app tile is preserved. No floral or segmented radial motif is used.

Created with the built-in image generation tool on 2026-09-29, then exported to standard macOS icon sizes with `sips` and `iconutil` (no CLI image-generation API).

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for Lucid Disk, an open-source disk space explorer. Generate one centered 1024x1024 square icon, no text. Deep midnight navy rounded-square app tile with generous transparent outer margin and clean smooth silhouette. Within tile: one large optically precise translucent glass lens/disk, seen straight on, with 3 nested uninterrupted concentric circular rings etched in cyan and cool blue, subtle refractive highlights and a tiny central aperture. A single restrained prismatic glint gives premium dimensionality. The form is circular storage and clarity, NOT a camera body. Sophisticated minimal native macOS app icon, crisp bold legible at 32 pixels, subtle material depth, no clutter. Absolutely no flowers, petals, rainbow radial segments, pinwheels, sunburst wedges, leaves, lettering, watermark, or mockup context. Genuine transparent canvas outside the rounded-square tile.
