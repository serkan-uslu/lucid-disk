# Lucid Disk icon

`AppIcon.png` is the source artwork: a deep navy rounded tile with three segmented rings around a bright center, echoing the app's disk map. `AppIcon.icns` and `AppIcon.iconset/` are exported mechanically with `bash Tools/build_icon.sh`. Transparency outside the tile is preserved.

The same artwork is used by the website (`website/public/`), the promo video (`video/public/app-icon.png`) and store listings, so every surface shows one mark.

Created with an image generation tool on 2026-09-29 and selected from three directions; exported to standard macOS icon sizes with `sips` and `iconutil`.
